# よくある質問

よく聞かれる質問への簡単な回答です。ここに載っていない質問がある場合は、フッターの **フィードバック** リンクをクリックして、Discord でお尋ねください。

## SCXtool が行った変更を元に戻すにはどうすればいいですか？

簡単です、いつでも可能です。SCXtool はゲームの元のファイルを直接編集することはないため、バニラ状態に戻すのはワンクリックです。

- **ツールバー → その他 → ローカライズをクリア** で、SCXtool が書き込んだカスタム `global.ini` を削除します。ゲームはすぐに内蔵のテキストに戻ります。編集内容が失われることはなく、アプリ内に保存されたままなので、いつでも再適用できます。
- 全部消すのではなく、1つ前のバージョンに戻したい場合は？ **ツールバー → その他 → バックアップを復元** で、タイムスタンプ付きのバックアップにゲームファイルを戻します（SCXtool は直近5個のバックアップを保持し、適用のたびに新しいものを作成します）。
- **Game Settings** タブで何かを変更した場合は？ そのタブの **Backups** をクリックすると、以前の `attributes.xml` や `actionmaps.xml` を復元できます。SCXtool は保存のたびに事前にコピーを取り、ファイルごとに直近5個を保持します。

個人の編集内容は、ゲームとは別に、SCXtool のデータフォルダー内の `user.ini` に保存されているため、ゲームファイルをクリアしても影響を受けません。

## SCXtool を使うとBANされますか？

SCXtool が編集するのは、ローカライズのテキスト（ゲームが表示する文言）と、Game Settings タブで変更したゲームのオプションとキー割り当てだけです。ゲームのロジックには一切触れず、優位性を与えることもなく、CIG のサーバーと通信することもありません。私たちの変更は**問題ない**はずです。

CIG はコミュニティによるローカライズを公式に支持しています。彼らの [Community Localization Update](https://robertsspaceindustries.com/spectrum/community/SC/forum/1/thread/star-citizen-community-localization-update) の投稿では、プレイヤーによる翻訳への公式なサポートが示されており、これは SCXtool が行うようなローカライズ編集を明示的に許可していると私たちは理解しています。

知名度の高いストリーマーも同様のローカライズプロジェクトを公然と運営しており、誰も中止を求められていません。

とはいえ、SCXtool の使用は自己責任でお願いします。私たちの変更は問題ないはずですが、あなた自身が行うことについては、発生しうる損害の責任はあなたとその関係者にあります。ある変更が適切かどうか分からない場合は、見た目だけの変更にとどめ、バックアップを取っておいてください。

## SCXtool はどのファイルを変更しますか？

以下のファイルだけで、あなたが操作したときにだけ書き込みます。

- `StarCitizen\<チャンネル>\data\Localization\<言語>\global.ini` — 選択したチャンネル（LIVE、PTU など）と言語のゲームローカライズファイルで、**拡張を適用** をクリックしたときに書き込まれます。SCXtool はまず既存のファイルをバックアップしてから、マージ結果を書き込みます。
- `user.cfg` の `g_language`。ゲームが正しいローカライズを読み込めるように、同時に設定されます。
- `StarCitizen\<チャンネル>\user\client\0\Profiles\default\` にある `attributes.xml`（ゲームのオプション）と `actionmaps.xml`（キー割り当てとコントローラーのオプション）。**Game Settings** タブで **Save to Game** をクリックしたとき、またはそのバックアップを復元したときだけ書き込まれます。SCXtool は書き込む前に各ファイルをバックアップし、ゲームの実行中は書き込みません。

ゲームのインストール内の他の部分には一切触れません。

SCXtool が自身の使用のために生成するもの（ソースキャッシュ、拡張ファイル、バックアップ、`user.ini`）はすべて、ゲーム内ではなく SCXtool のデータフォルダーに保存されます。

## なぜ Windows はこのアプリを「認識されていません」と表示するのですか？

SCXtool がまだコード署名されていないためです。Windows の SmartScreen や Smart App Control は、署名証明書が登録されていない発行元からの新しいアプリを、たとえ完全に安全であってもフラグ表示します。これは「これまで見たことがない」という警告であり、「これは危険だ」という警告ではありません。

実行するには：SmartScreen のプロンプトで **詳細情報 → 実行** をクリックしてください。Smart App Control が完全にブロックしている場合は、そのプロンプトからアプリを許可するか、一時的に Smart App Control をオフにしてインストールし、その後再度オンに戻してください。

コード署名は今後の計画に含まれており、実装されればこの警告は表示されなくなります。それまでは、本物のビルドであることを確認するため、公式の GitHub リリースからのみ SCXtool をダウンロードしてください。
